Formation extensions and current source

GeoGenesis ProcessPlugin receives mutable World, read-only Hydro/Climate/Geology, dt years, returns MassBalance; built-in meteor impact example demonstrates actual extension point. New landforms can be bounded deterministic stages or plugins. Plugins run after built-in chain, so refresh affected hydrology and climate/material descriptors after geometry changes; if intended to age naturally insert initial stage before age. Surface elevation includes sediment (World); do not add loose sediment twice. Fluvial has implicit detachment-limited, transport-limited and SPACE laws; hillslope conservative edge diffusion; aeolian uses simplified prevailing wind. Formation-time drainage estimates not finite runtime flows. At runtime accumulate nonlinear erosion forcing (shear/threshold exposure, not simply mean Q), actual sediment/dust and material removal, commit terrain edits and dirty topology. New caves, overhangs and finite ore require 3D recipe + edited solid state, not surface-height perturbation alone.

GeoGenesis priority flood has seeded/rank-queue and D8/MFD. PyFlwDir provides actual supplied-outlet and unit-catchment routines. Neither magically solves inverse regional refinement. Store parent crossings, outlet and spill elevation, terminal basin identities, feature profiles; resolve cross-window dependencies before claiming exact. Cropping before a remote saddle in independent probe gives false 1m instead of true 5m. Use sparse regional pages/latent constrained features; no all-creek precomputation. 50% land in 4000km square, illustrative drainage density 1km/km² and 100m segments imply 80M segments, 4.77GiB at 64B before links. Aggregate minor headwater response and persist consequential individual feature changes; do not promise exact unseen local state if only aggregate known.

Published implementation c7b4ede9af45a67a6ddd3d65cd5685d3af79c320: native flux already contains local inertia and conservative exchanges; groundwater head/conductance/SPD; air face transport, morphology, soil exchange useful existing evidence but no reuse preference. Historical Flood078 1124 CPU-ms/game-s vs 25 target; earlier SWMM/CaMa failures; no revival of old LandscapeChannels/preparation, no broad legacy API/save compatibility. Compare narrow primitives only under same acceptance gates. Local unpublished code not inspected. Aokana paper’s explicit lack of runtime voxel edits prevents replacement of Zylann based solely on rendering benchmark.

Hydraulic method limits and pressure results

Ordinary reach IRF uses normalized response weights and finite transit queue; source mizuRoute conv_upsbas_qr has volume and future flow, clamp and shift, short-length branch resetting stock. Qualify exact remaining inventory, cap/withdrawal, delayed release and re-route when topology changes. Do not count queue and reach volume twice or lose capped release. Promote downstream shortcut to signed head mode before backwater/overflow/control matters; do not run both simultaneously over same water. Local inertia Qnew=(Qold+gAdt(etaA-etaB)/L)/(1+gdtn²abs(Qold)/(R^(4/3)*A)). Need monotone connected V(stage), face area/conveyance/sill/actual path length; no bathtub flood. Quasi-steady diffusive signed Manning challenger for slow flows. Use applicable control/rating laws or full shallow-water momentum for rapid falls/dam breaks. Sibling 1m dam-break local inertia normalized L1 ~40%, HLL 2.64% with exact ledger: local inertia not universal. FluxCell actual MIT source has HLLC, hydrostatic reconstruction, scalar and CPU reference; author 610–700M updates/s preprint not peer-reviewed nor local benchmark. Editable bed retains depth, solid mask fixed, GPU batches/readbacks/ownership need qualification; no full-island 1m solver.

Complementary actual independent C++20 O3 single thread virtual EPYC 9V74, 100x100km synthetic all-active rectangle, closed boundaries, 100mm/h x1h, piecewise volume and rectangular face, no true geometry/land/air/save/render. 1km/30s: 0.025300 CPU-ms/physical-s. 250m/30s: 0.383678; 250m/10s: 1.179750; 250m initially 5m/10s: 1.150764. 30.72MB arrays at 250m, max residual relative to initial+rain 3.42e-13. Fixed dt not certified. Tests stage inverse, no incoming below crest, reversal after momentum reset, simultaneous donor cap and gate; deliberately oversized 2-cell step oscillates 1->0 vs equilibrium 0.5 despite conserving water. Need finer actual reference, real geometry and timestep convergence.

Atmosphere and volumetric clouds

Weather3D parent hydrostatic anelastic C-grid 12 layers RK3, pressure projection each stage with DFT/Thomas and iterative terrain correction. Source includes Earth steering and internal moisture/soil clamps; no whole adoption. Compare 32/16km 8-layer reduced prognostic first, 4 layers only if storm/vertical accuracy passes, regional 8km/parameterized narrow convection. Cheap evolving diagnostic wind/heat benchmark control is not full weather. Need evolving pressure/wind, vertical exchange, terrain uplift/rain shadow, saturation and latent heat, seasonal/diurnal forcing, finite moisture. CliMT C-binding column physics is alternative reference with independent condensation/mixing/surface switches, JCM SPEEDY independent 8-level reference, COARE bulk exchange. CliMA 0M threshold relaxation analytic fixed-excess removal, adapt actual phase/fall-delay; ERF Kessler warm rain challenger. HBV snowpack solid/liquid degree-day melt/refreeze with actual stock and liquid retention; ice/heat approximations explicit. Weather and plant fields include wind direction/speed, humidity/temp, radiation, precipitation and wetness. Rivers velocity Q/A, wind-driven damped slab current for lakes/ocean, optional Coriolis; coastal storage/flow if surge impacts gameplay; no separate decorative physical water authority.

Independent constant-wind tracer 4000km 1D periodic, Gaussian sigma64km, 720km translation, CFL.1: 32km first-order L1 82.53% vs MC21.28%; 16km 59.22% vs6.95%; 8km39.06% vs1.91%. Both mass errors <1e-15. Varying velocity ordinary interpolation loses 3.53% in separate toy example, not Weather3D measurement. Sibling tests include narrow sigma12km: even 8km MC inadequate for tested threshold; subgrid convection or refine where needed. Sibling AVX2 four-scalar 16km 8-layer transport median 2.764ms/step only, no pressure/vertical/etc. Prefer MC/TVD, not upwind-only; validate actual multi-D flux-consistent mass and thermal dynamics.

True volumetric clouds mandatory. Sibling record source-reviewed SunshineClouds2 (MIT Godot compositor) and Godot-Cloud-Worlds (MIT SDF skipping). Test actual bounded 3D density shape volumes driven by atmospheric cloud mass/height/coverage and wind, 480x270 at 1080p, 24–48 primary steps, cheap light, empty-space skip, depth-aware temporal history/rejection. 32 primary steps all-screen 4.147M samples vs 132.71M full-HD/64; not GPU benchmark, nested lights and overlapping volumes can dominate. Eight 128³ R8 volumes 16MiB before mips; share cloud shape assets, not per-cloud grids. True local/fly-through density, distant sky cached if consistent, no sprite-only substitution. Weather determines amount/form and motion, visuals do not own moisture. Test above/inside/below, storm/dawn/night, depth edges, motion and time acceleration on RTX2070S. No measured GPU result.

Bounded gate and Codex brief

No final technology lock beyond user’s terrain soft lock. High risks: actual refined topology/geometry without fine-world preprocessing; regime switching and stable subgrid flood accuracy; real reduced circulation plus mixed-phase heat; global physical/game-time pacing; true cloud GPU cost. Full compatibility designed, not validated. Proposed tolerances before tests: topology/closed barriers hard pass, compare stage/arrival and extent with independent finer reference (initial example extent IoU>=.85, arrival within 10% or one coarse step, relevant stage error <=.1m or 10% depth; select scenario thresholds before execution). Normalize conservation by transferred amount/local balance as well as world inventory.

  1. ~1.5h work allocation: pin actual checkout, build GeoGenesis single-shot age/export, explicit original/filled fields, 256km macro and 4000km macro timing separately. No dense fine generation. If build fails, labeled known-answer fixture only, not natural baseline success.
  2. ~1.5h: bounded region plus adjacent seam, shared outlet/closed basin, selected PWG landform and Zylann render; compare repeat/reload and exact geometry/cave if possible.
  3. ~2h: qualify mizuRoute-type IRF (finite pending/withdrawal/promotion), Wflow-type subgrid head transport and FluxCell CPU reference on known-answer dam/levee/arrival. Do not require successful wholesale port. Compare native only same criteria, no preference.
  4. ~2h: actual CFE donor and finite rain/ET/heat, MC transport, reduced wind/pressure donor or explicit limited control; test downwind rain, cloud phase and snow; no claim full atmosphere if prescribed.
  5. ~1h: normal host connected small natural terrain/water/weather, terrain edit and save/reload, actual visuals (true volumetric cloud smoke test if feasible), offscreen, inclusive costs and exact blockers. Subsequent whole-island actual storm, long-distance travel and population gate, not accepted on toy data.
    This is a bounded one-day qualification proposal, not a promise to finish all systems in one day. Codex: read accepted Brain records and pinned source, one writer, separate scratch lineage; retain Godot/Jolt/Zylann, no LandscapeChannels, no whole app transplant, no new scheduler/voxel tree by default. Follow gates, record actual commands/source/binary, CPU/game and physical seconds, GPU/RAM/VRAM, init/prep/rebuild, visual result, failures and remaining uncertainty. User authorization needed for game runtime changes; no main merge here.
