Spatial architecture selection

Status: provisional engineering selection, source-qualified only (25 November 2026). Read accepted LOD requirement, world scale, authority, performance targets, terrain contract, navigation contract, water contract and prior qualification plan. No runtime implementation or performance acceptance.

1. Current implementation and replacement delta

The published source at b6003fe9f89d90b59bb9c847096c558f86e9fb71 has a working conceptual separation between Zylann rendering/residency and native navigation. It does not establish inexpensive coarse simulation of all distant effects. Pinned source audit.

The pinned VoxelGenerator header supplies multithread-safe block generation with integer origin and LOD, optional series query, and a caller-owned voxel buffer. VoxelViewer allows visual/collision/data-notification needs to differ. SQLite stream format supports string and wider binary block keys. These already cover much of fine residency; avoid a new general-purpose voxel cache or per-colonist viewer. The pinned tree already includes FastNoise2; use existing graph/noise facilities where useful, do not import another noise package by default.

2. Select the simple structure for the pilot

Shared metric integer X/Z coordinates and local Y-up metre geometry, not a universal scene-tree hierarchy. One world identity/configuration. Existing checked 64-bit coordinates can be retained if verified; render relative to a local origin. Use a bounded rectangular world initially. Optional periodic topology must preserve actual extent, wrap intersections and seam identities; never silently pad the world. Arbitrary world dimensions use exact partial-edge area and boundary handling.

Logical addressing: a 16 km region/page, integer page coordinate and domain/field/level identifier; globally dense macro row-major arrays and a compact direct page directory. Region keys locate data, not ownership. Dense hot indices are not durable IDs. Use checked floor division for negative coordinates; local float coordinates only after origin subtraction. No pointer-rich octree for ordinary horizontal cells. Existing 16 m/32 m voxel blocks remain an independent 3D lattice. 250 m horizontal samples need not align to every voxel block. Where domains differ, exact overlap weights and feature contacts link them. Optional Morton sorting is a later measured optimization, not a prerequisite.

Do not require all 250 m pages to exist simultaneously. A region may have persistent coarse water, vegetation or human activity when its fine payload is absent. If an authoritative state has been refined or edited, keep its actual state/delta in memory or storage and ensure due events are applied; evict derived cache first, not physical consequences. Persist unresolved incoming amounts/time horizons until processed. No every-page catchup that silently stalls large active worlds. Base geometry and current edit layers are distinct; a coarse surface cannot be used as exact cave occupancy. A narrow stream must remain a feature even below the regional sample spacing.

Resource arithmetic, not measurements

  • 4,000 km at 16 km gives 250 x 250 = 62,500 page descriptors. At an illustrative 32 B each: 1.91 MiB, before payloads.
  • 4 km global samples: 1,000,000 cells. At 64 B/cell: 61.04 MiB.
  • 1 km global samples: 16,000,000 cells. At 16 B/cell: 244.14 MiB; at 64 B/cell: 976.56 MiB.
  • 250 m global: 256,000,000 cells, 15.26 GiB at 64 B/cell. A single 16 km page is 64² samples, 256 KiB at that stride; a 1024-page working set is 256 MiB. Not a mandated cache cap.
  • 1 m global 2D footprint: 16 trillion samples, about 931 TiB at 64 B/sample, excluding vertical geometry.

Birth/age, derived geometry, scratch, active owners, caches, snapshots, edit journal and autosave must each be measured; a packed illustrative byte stride is not a memory estimate for GeoGenesis or any real solver. Bound total work with domain-specific cadence and active partitions. A storage page is not a simulation unit and must not force every owner to tick together.

3. Geographic data flow

  1. Birth and age: run the accepted provisional GeoGenesis single-shot connected coarse simulation. Export final original surface, soil/sediment/geology, drainage area/receiver/order and refreshed climate/diagnostic runoff in explicit units. Use hydrology::route after age; lake fill depth is capacity diagnostic, not finite inventory. Preserve terminal basins; do not discard water at the root. Do not use the initial-only tiled path as if it aged regions. One-time field handoff; no second mutable formation world.
  2. Coarse topology and boundaries: retain stable downstream contacts, closed-basin/spill identities, crossing positions and profiles, catchment extent and region revisions. Each region uses agreed physical boundary data derived once from the parent geography; arbitrary tile boundaries are not outlets. A region with no explicit drain is not automatically sea. Persist a resolved topology change when a dam or incision changes a crossing. Evaluate narrower drainage-aware refinement algorithms for tributaries before selecting them.
  3. Detail realization: pilot the MIT Procedural World Generation donor. Its CPU channel and slope-conditioned detail routines accept supplied coarse/river inputs. Use or port only the reusable numerical pieces after license notices and source equivalence tests. Stable bed/bank geometry, not current water stage, constrains terrain. Sample globally keyed deterministic detail; bounded halo with canonical constraints; if drainage depends beyond halo, request/reconcile the affected parent/basin summary, not a new arbitrary border outlet. A render-dependent blend is not physical terrain authority. Additional source review found a deterministic local creek/trunk generator; its authoritative parent-outlet and closed-basin consistency remains open. See formation comparison.
  4. Current geometry: Zylann renders/generates from the canonical region recipe and edit overlay. Coarse consumers derive geometry from the same recipe, feature profiles, and durable edits. Provide direct native block/batch evaluation without requesting scene nodes, voxel viewers or GPU readbacks on routine coarse queries. A mesh may approximate but cannot alter true bank/barrier or cave occupancy. Fine SDF acquisition is for local edits, exact interactions and exceptional corrections.
  5. Process state: each solver owns its evolving quantities. Coarse surface stores retain distinct connected partitions, stage-volume and connections; channel geometry is a constraint, not water inventory. At promotion partition volume and constituent mass to children; at restriction aggregate accepted amounts; reconcile cross-boundary flux over the same interval. A camera movement alone must not change where water flows, how long travel takes or resource totals. Live erosion commits terrain deltas from actual forcing; do not recarve geometry each time a river rises.

A newly generated fine tributary may not contradict previously simulated parent runoff/route/basin outcomes. Its latent recipe or aggregate partition must constrain the prior simulation. If unresolved, label precision and require reconciliation before claiming exact topology, not a fictional fully resolved network. Closed depressions and narrow streams cannot be represented solely by average height. Large regional reroutes may require wider topology repair; local cost guarantee is limited to genuinely local edits.

Minimum custom code: field handoff/versioning, checked keys and page residency boundary, existing numerical-kernel adapter, feature-to-current-terrain contract, boundary reconciliation and dirty publication. Not a new custom renderer, sparse volume format, terrain erosion engine or navigation runtime. The outstanding tributary construction is real engineering risk, not hidden behind the term ‘hierarchy’.

5. First bounded qualification package

See spatial qualification. First run should be limited to formation plus geometry/refinement; no water runtime replacement, atmosphere, ECS migration or massive game build yet.

  1. Confirm actual checkout, dependency pins and current Zylann generator extension boundary. Use the existing build tools and separate scratch lineage. Test negative coordinates, region boundaries, arbitrary edge extents and 4,000 km indexing without fine allocations.
  2. Build the pinned GeoGenesis core with a minimal export, age one 256 km seed, refresh drainage, measure birth, age and field handoff separately. First use a small known two-region topological fixture to validate the donor, then use actual naturally generated terrain; do not present a manually placed creek fixture as a natural river generation pass.
  3. Exercise the source donor CPU routines with a predeclared pair of adjacent regions, crossing channel profile, terminal depression, slope and spill control. Measure source baseline and native integration separately. Compare same sample positions from both evaluation orders, with neighbor absent/present, after eviction and after independent restart. Parent outlets, shared bank/bed profiles and basin identities must agree; no false drain or inserted water. For a roughly 1 m stream verify continuous feature geometry at finer local measurement resolution, and validate what the selected voxel/mesher resolution can actually represent.
  4. Demonstrate an edit (dam or excavation) changes the relevant topology/summary and persists, including an offscreen edit. Track affected pages, requested voxel blocks and bytes. Invalidated data returns pending/coarse until its actual dependency is resolved; unrelated pages do not rebuild.
  5. Measure complete small-world startup to macro-ready, feature-ready, and interactive terrain-ready. Then scale the macro/address/page directory probe to 4,000 km, not a fake fine-world test. Track inclusive CPU time, peak memory, generated/resident blocks and per-page latency. Compare images in the normal Godot host if integration reaches that point. Use historical 1 s 256 km macro/initial target and few seconds large-world macro separately from aging; record misses without altering physical clocks or excluding prep.

Pass criteria for qualification: no dense fine-world allocation; deterministic same-revision shared authoritative samples (within declared numeric precision), feature/closed-basin continuity, durable edit and bounded resident work independent of camera; agreed geometric error thresholds frozen before tests; actual measured cost and rendered quality. Failure returns to candidate research, not a mandate to build an entire new terrain engine. Broad storm, conservative transfers and 800 km travel are the subsequent consumer gates, not proven by the spatial fixture.

Open: Q-GRID exact domain resolutions; Q-REFINE fine tributary/saddle construction and topology summaries; hydraulic and atmosphere algorithm selection. This record selects a structure and a first permissive refinement donor to test, not finished solver implementation.

Formation review supplement

The spatial structure remains proposed unchanged. The subsequent formation comparison supersedes the earlier assumption that only GeoGenesis should be evaluated for birth. Test Procedural World Generation as a full alternative before committing to the source of the macro fields. The existing GeoGenesis-only fixture remains a comparison path, not a mandate.
