World formation comparison and remaining terrain scope

Source review: 25 November 2026. Both candidates MIT. Existing provisional GeoGenesis selection remains subject to comparison; recommend Procedural World Generation first in the surface-formation comparison because the user values the demonstrated geographic quality. Neither is validated on target hardware. No engine code modified.

GeoGenesis source: initial formation, age driver, geology, mineral scoring. PWG source: pipeline, LEM, age config, landforms, arid, cliffs, hydrology, creeks, creek tests.

Recommendation: compare whole formation outputs, not stack two full generators. PWG’s explicit landform diversity and local creek implementation may avoid significant custom engineering. GeoGenesis is better aligned with chronological coupled age and material inventories. A beautiful demo does not by itself establish native runtime speed, physically correct finite water, or 3D geology. PWG’s rendering and visual embellishment should not be mistaken for the physical terrain. If PWG wins, consider only needed compatible GeoGenesis rock/stratigraphy and geological-process kernels, not a second world owner. If GeoGenesis wins, borrow PWG’s targeted landform/creek/geometry routines rather than running PWG’s entire macro pipeline afterward.

Bounded selection gate

  1. Run both pinned upstream generators headlessly using the same physical world width and comparable output resolution/land fraction/climate settings. Use a small reproducible seed set representing humid mountainous islands, dry plateau/canyon terrain and volcanic or glacial terrain. Seeds need not map to identical geography across different algorithms. Inspect final exported elevation, not renderer exaggeration, and measure cold macro generation, aging/evolution, refinement/export and peak working memory separately. GeoGenesis’s author timings are not a direct comparison; PWG has a source-inspected benchmark entry point.
  2. Compare actual plateau/cliff profiles, river continuity, lake/outlet connectivity, relief variation, geology/material information, age controls and age-dependent changes. Freeze tolerances and visual evaluation views before testing. Report which landforms are process-driven vs explicit stamps; both are legitimate if coherent and configurable.
  3. Test actual natural fine river/creek realization, including 1 m feature geometry where representable, cross-page continuity, closed basins, deterministic re-generation and no view-dependent physical geometry. Existing creek tests are useful starting evidence, not our validation. A fixed height callback and persistent parent routing/finite inventory contracts are mandatory.
  4. Only after upstream evidence, compare native interop costs and one bounded Godot/Zylann view with true caves and materials. Select one source. Do not start a large port or new framework to make either candidate fit. Probe 4,000 km coarse scaling with no dense fine allocations. Distinguish failed/partial/accepted results.
